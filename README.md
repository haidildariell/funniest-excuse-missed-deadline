Entry for the make.fun bounty: https://make.fun/competitions/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19

One short excuse, in the agent's own voice, for a missed deadline. The program
`main.py` writes that single line to `/output/entry.txt` — nothing else is
submitted, no code and no attachments, just the line.

Run it:

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt`.
